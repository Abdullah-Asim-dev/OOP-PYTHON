## Practical Approach

Instead of focusing only on theory, I practiced each concept through small coding examples.

For example:

```python
class Vehicle:

    def move(self):
        print("Vehicle is moving")


class Car(Vehicle):

    def move(self):
        print("Car is moving")


car = Car()
car.move()
```

This demonstrates how **inheritance and polymorphism** can work together in a practical Python program.
